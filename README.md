# Battleship Artillery

Rozpracovaná Unity hra s bitevními loděmi. Modely lodí jsou z Blenderu (`Assets/Models/Ship/`).

- **Spuštění:** otevři složku v Unity Hub, verze editoru `6000.3.12f1`, a spusť scénu `Assets/Scenes/SampleScene.unity`.
- **Hotovo:** modely lodí (`.blend`, `.fbx`), výchozí scéna, nastavení URP a Input System.
- **Zatím nefunguje:** žádné vlastní skripty, tedy žádná hra, jen scéna s modely.
